    How it works

    A model, not a guess

    What you type is read by a model trained to recognise patterns in how people describe what they're going through, combined with your age band and the current Australian season, and turned into a ranked set of recommendations. Nothing here is a diagnosis — it's a starting point for finding what might help today. If things feel like more than a tough day, the support links in the footer are there any time.
